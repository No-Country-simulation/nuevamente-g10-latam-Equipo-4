# Primeiro estudo — redes na nuvem

Exemplo didático escrito pela equipe Atlas. Não é documentação oficial Oracle.

## Rede privada

Uma Virtual Cloud Network (VCN) é uma rede virtual configurável. Sub-redes organizam recursos dentro dessa rede.

## Saída para a Internet

Um NAT Gateway permite conexões de saída de recursos privados. Ele não permite conexões novas iniciadas diretamente pela Internet para esses recursos. Rotas e regras de segurança continuam necessárias.

## Estudar com evidências

Ao explicar uma configuração, cite a passagem da fonte. Se a informação não estiver no material, explicite a limitação em vez de inventar uma regra.

## Perguntas para praticar

O que uma sub-rede organiza? O NAT Gateway dispensa regras de segurança? Que trecho apoia sua resposta?
